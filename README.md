# NoSqlLab2

Приложение использует Java 21, Spring Boot, Cloud Firestore и Riak KV. HTML и API обслуживает один сервер.

## Локальный запуск в PowerShell

В проекте используется существующий локальный `src/main/resources/credentials.json`. Maven включает его в JAR. Сборочный артефакт предназначен для локального запуска.

Для отдельной учебной установки Riak запустите один контейнер и создайте типы бакетов.

```powershell
docker compose up -d --wait
Get-Content -Raw docker/riak-init.sh | docker compose exec -T riak sh -s
$env:RIAK_SECONDARY_PORT = '0'
.\mvnw.cmd spring-boot:run
```

Приложение открывается по адресу `http://localhost:8080`. С существующим кластером можно использовать `RIAK_HOST`, `RIAK_PORT`, `RIAK_SECONDARY_HOST` и `RIAK_SECONDARY_PORT`. По умолчанию клиент использует порты 8087 и 8089 на локальном хосте. Скрипт инициализации с `n_val=1` предназначен для узла из Compose. Тип `expiration_bucket` нужен демонстрации токенов, срок действия проверяет приложение. Тип `counters` нужен счётчику созданных заявок.

[Конфигурация образа kefirgames](https://github.com/kefirgames/riak_docker) описывает сетевые параметры и переменные Riak.

## Firestore

Первый вход, регистрация или запрос демонстрационного токена строит индекс нормализованных имён для старых документов `users`. Если старые имена отличаются только регистром, для входа в каждую из таких учётных записей требуется её точное написание. Поле старого пароля удаляется при успешном входе. Составные индексы для каталога и истории описаны в [firestore.indexes.json](firestore.indexes.json). Установите их в нужной учебной базе, если их там ещё нет.

Чтобы открыть административные операции, установите `role = ADMIN` в документе нужного пользователя в Firestore и войдите заново. Запуск миграции через вкладку согласует верхнеуровневое поле `status`, по которому Firestore фильтрует каталог, с `updatedStatus.code`, который показывает карточка товара. Повторный запуск пропускает исправленные документы.

Каталог и история возвращают `X-Next-Cursor`, когда есть следующая страница. Передайте его как `after` с теми же фильтрами. Для HTTP-клиента без браузерных заголовков выполните `GET /api/auth/csrf`, сохраните cookie сессии и передайте значение `token` в заголовке `headerName` для изменяющих запросов. После входа токен следует получить заново.

## Сборка

```powershell
.\mvnw.cmd verify
```

Проверки Spring запускаются с подменёнными Firestore и Riak и не требуют доступа к рабочим данным.
